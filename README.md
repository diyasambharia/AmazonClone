# AmazonClone
This project is a front-end clone of the Amazon homepage, built entirely using HTML and CSS. The goal is to replicate the layout and styling of Amazon's website to practice responsive web design, semantic HTML structure, and modern CSS techniques.

🛠️ Features :
Responsive navigation bar with logo, search bar, and icons

Hero section with promotional banner

Product grid showcasing various items

Footer with multiple columns (links, policies, etc.)

Fully responsive design for different screen sizes
